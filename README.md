# 📊 Product Data Exploration Using Excel

## 📌 Project Overview

This project focuses on exploring and analyzing product data using Microsoft Excel.
The dataset contains information about different products, including Product IDs,
Product Names, Brand Names, Quantities, Categories, and Prices.

The main objective of this assignment is to develop foundational data analysis
skills using Excel formulas and functions to summarize data, apply logical
conditions, perform conditional calculations, and extract useful information
from text fields.

This project demonstrates essential Excel techniques for data exploration
and preparation for further analysis.

## 📈 Excel Functions and Techniques

The following Excel functions and techniques are used in this assignment.

### 1. Data Summarization
- `SUM()` – Calculates the total of numerical values.
- `AVERAGE()` – Calculates the average value.
- `COUNT()` – Counts cells containing numbers.
- `COUNTA()` – Counts non-empty cells.

### 2. Logical Functions
- `IF()` – Evaluates a condition and returns a result based on whether it is TRUE or FALSE.
- `AND()` – Checks whether multiple conditions are TRUE.
- `OR()` – Checks whether at least one condition is TRUE.

### 3. Conditional Aggregation
- `SUMIF()` – Calculates a total based on a single condition.
- `SUMIFS()` – Calculates a total based on multiple conditions.
- `COUNTIF()` – Counts cells that meet a condition.
- `COUNTIFS()` – Counts cells that meet multiple conditions.
- `AVERAGEIF()` – Calculates an average based on a condition.

### 4. Text Manipulation
- `LEFT()` – Extracts characters from the beginning of a text string.
- `RIGHT()` – Extracts characters from the end of a text string.
- `MID()` – Extracts characters from a specified position.
- `LEN()` – Returns the number of characters in a text string.
- `TRIM()` – Removes unnecessary spaces from text.
- `CONCAT()` – Combines text from multiple cells.
